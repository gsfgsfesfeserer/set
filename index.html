🛠 Установка — 3 шага

Займёт 5 минут. Всё делается без командной строки, кроме одной команды.

1

Установи Ollama

Ollama — движок, который запускает модели ИИ на твоём компьютере.

  • Зайди на ollama.com/download
  • Скачай Windows-версию
  • Запусти установщик, жми «Next» до конца
  • После установки в трее появится значок ламы 🦙
2

Скачай модель

Открой меню Пуск → найди Ollama → запусти. Откроется чёрное окно терминала. Напиши там:

ollama pull qwen2.5:7b

Подожди, пока скачается (~4.7 ГБ). Потом проверь:

ollama list

Должен появиться qwen2.5:7b в списке.

3

Запусти сайт

Нужен Python (проверь: открой cmd и напиши python --version). Если есть — запусти сервер в папке с index.html:

cd C:\Users\ТВОЁ_ИМЯ\Downloads python -m http.server 8000

Открой в браузере:

http://localhost:8000/index.html

Готово — увидишь зелёную точку и сможешь общаться с ИИ.

🌐 Полный доступ — для других

По умолчанию сайт виден только тебе. Вот 3 способа открыть его другим — от простого к сложному.

📶

Локальная сеть

Друзья в той же Wi-Fi сети увидят сайт. Работает 1 минуту.

ipconfig → IPv4: 192.168.X.X → http://192.168.X.X:8000/index.html
Легко
☁️

Cloudflare Tunnel

Публичная HTTPS-ссылка для всего мира. Живёт, пока открыт туннель.

cloudflared tunnel \ --url http://localhost:8000
Средне
🚀

VPS + Ollama

Постоянный хостинг для всех. Нужен сервер с GPU (~5$/мес).

# на сервере: ollama serve # сайт размещаешь на VPS
Сложно
🔒

Важно про «полный доступ»

Даже если откроешь сайт миру — чат работать не будет, потому что на компьютере гостя нет Ollama. Каждый пользователь должен установить Ollama и скачать модель у себя. Это и есть суть Анти Клауда: у каждого — свой ИИ.

Если хочешь именно общий ИИ для всех — нужен API (например, Pollinations) или VPS с Ollama и открытым портом. Но это уже не локально.
